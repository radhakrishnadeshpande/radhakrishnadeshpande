## 👋 About

MS by Research (CSE) at **IIIT Hyderabad** and engineer at **CVIT**. I build systems that read and search documents: OCR, multilingual NLP, and retrieval-augmented QA for low-resource Indic scripts.

- 🔭 **Research:** cross-lingual retrieval and QA over noisy, multi-script archives (Hindi, English, Punjabi)
- ⚙️ **Engineering:** large-scale OCR pipelines and Elasticsearch search over their outputs
- 🌱 **Interests:** OCR, domain adaptation, information retrieval, agentic RAG

## 🚀 Selected Work

**CLiGRA: cross-lingual retrieval + QA for multilingual archives**
Hybrid pipeline combining lexical search and semantic retrieval with LLM reasoning. It answers in the user's query language and is grounded in retrieved documents, which reduces hallucination. Evaluated on the 200,000-page Punjab Vidhan Sabha archive.
`Python` `FAISS` `Django REST` `NLTK`

**Label-free Indic OCR adaptation**
Self-supervised domain adaptation that improves OCR on low-resource Indic scripts without labeled data.
`PyTorch` `CRNN` `SSL`

**OCR + search infrastructure at CVIT**
Fine-tuned CRNN models, high-throughput OCR over thousands of document images, and Elasticsearch search with custom analyzers and schema tuning.
`Python` `Elasticsearch` `Docker`
